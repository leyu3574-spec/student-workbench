# 学生工作台 0.8

个人自用，本地优先。目前只含基础功能：教学周、课表（按周显示、PDF 导入、CSV 导入、手动录入）、作业待办、今天的日程整合。数据只存在设备上。

“我的 → 个性化”里目标填“南京大学”，首页会出现一场从南工跑到南大的比赛：陪跑的 TA 按学期进度跑，作业按时 KO 就能跟住 TA，期末一起撞线。TA 的名字、身份（目标、榜样、陪伴）和想对你说的话都能改。

- 手机（安卓）：GitHub 自动打包 APK，装上就是独立 App，截止提醒走系统通知。
- 平板（鸿蒙 5）：装不了 APK，用同一套代码的网页版，浏览器打开即用。

## 第一次设置（一次性，电脑上操作最方便）

1. 在 GitHub 新建仓库，比如 `student-workbench`，设为 **Public**（代码里没有你的任何数据；公开仓库的 Pages 和 Actions 免费）。
2. 把 `student-workbench` 文件夹里的全部内容上传到仓库根目录，包括隐藏的 `.github/workflows/build.yml`。
   网页上传后在仓库里确认能看到 `.github/workflows/build.yml`；没有的话用 Add file → Create new file，路径填 `.github/workflows/build.yml`，把文件内容粘贴进去。
3. 仓库 Settings → Secrets and variables → Actions → New repository secret：
   - Name：`ANDROID_DEBUG_KEYSTORE`
   - Secret：把压缩包里 `签名密钥-粘贴到GitHub.txt` 的全部内容粘贴进去
   这把钥匙保证每次新版本都能覆盖安装、数据不丢。不要把这个 txt 上传到仓库。
4. 仓库 Settings → Pages → Build and deployment → Source 选 **GitHub Actions**。
5. 打开仓库的 Actions 页，选“构建”→ Run workflow（以后每次推送代码都会自动跑）。

## 安装

- 手机：构建完成后打开仓库的 Releases，下载 `workbench-0.8.x.apk` 安装（需要允许“安装未知来源应用”）。之后有新版本，下载新的 APK 直接覆盖安装。
- 平板：浏览器打开 `https://你的用户名.github.io/student-workbench/`。能否“添加到桌面”、离线打开，在鸿蒙 5 上**待验证**。网页版有新版本时，页面顶部会出现“有新版本”。

## 两台设备之间传数据

我的 → 导出备份，把文件发到另一台设备，再在那台上 我的 → 导入备份。导入按修改时间合并，不会用旧内容覆盖新内容。

## 0.8 新增

- 覆盖安装：构建时明确用仓库里的固定密钥签名，并核对签名指纹（日志里“安装包签名指纹”每次都一样）；没设密钥会直接停止构建。
- 语音：点“说完了”、“取消”或停顿后都会立刻收起，不再卡住。
- 时间轴：色块可以直接填名字、开始和结束时间；改了和待办同名的色块，待办也跟着改。
- 优先级：课和日程不动；你最新调整的块优先；其他块自动往后顺，不会互相重叠。完成的块不再挡路。
- 提醒体检：“我的 → 提醒”里逐项检查通知权限、悬浮横幅、后台运行、自启动，每项有按钮直达系统设置。
- 动效：参考 onetake 的一镜到底思路重写（没有搬它的代码）：弹窗从你点的地方长出来，切页像同一个镜头平移，KO 时有火花飞到赛况，排好的块从列表飞进时间轴，每天第一次打开有开场。

## 0.7 新增

- 语音：点麦克风弹出波纹面板，波纹跟着音量动；停顿 2.5 秒或点“说完了”自动结束，没听到也会自己关掉。
- 时间轴不再重叠：课、饭点、日程和你手动放的块优先，其他块自动顺到下一个空档。
- 时间轴上做完一块，待办里同步勾上；待办里 KO，时间轴也同步。
- 跟小助手说“某时间有事”，会同时写进时间轴（日程）和待办；已经定好的安排不会再被新方案占用，要改时间直接跟它说。
- 规划偏好、饭点、预计用时、提醒时间都改成自己填。
- 提醒改成悬浮通知，带“现在开始”“10 分钟后再提醒”两个按钮；手机设置里要打开横幅通知。
- 小助手记得的事收进一个格子，点开查看、增删。

## 0.6 新增

- 小助手改成自由聊天，什么话题都能聊；需要动安排时它调用工具，不再因为“格式不对”报错。
- 它给的安排先以方案卡片出现，你勾选取舍，点“排进时间轴”才会真正排上。
- 时间轴上长按色块可以拖动；点色块能改开始时间和时长，改过的块会固定住。
- KO 一项或提前做完，后面的块自动往前补位；到点没做的会提示“顺延”。
- 记忆完全自动：小助手每聊几句就自己总结你的习惯，在“我的”里只能看和删。
- 聊天框加了语音按钮。安卓 App 用系统语音识别，平板网页版用浏览器的语音识别，能不能用待验证；不支持时用输入法的麦克风。
- 每项作业可以单独设弹窗提醒（截止前 30 分钟到 1 天），App 开着时直接弹窗，不开时是横幅通知；不再需要“闹钟和提醒”权限。

## 0.5 新增

- 待办 → 每日：背单词这类没有截止、按天做的事，今天页可以一点打卡，会算进排计划和赛况。
- 今天页“我现在有空”：选有多少时间，给你三个现在最值得做的事。
- 计划会跟着你走：提前做完、打卡、KO，或者到点没做，后面的安排都会自动调整。
- 小助手（底部中间）：告诉它什么时候有空、没空、做完了什么，它直接改安排，每次都能撤销；它会记住你的习惯，在“我的 → 小助手记得的事”里能看和删。
- 保研之路：对手按固定配速跑到推免那天；按时 KO、每天打卡就甩开他，拖延和漏打卡会被他追近。终点日期按往年推免时间估的，待验证。

## AI 规划（0.4 起）

我的 → AI 模型：服务商选 DeepSeek，粘贴 API Key，点“测试连接”。模型默认 `deepseek-v4-flash`。API Key 只存在这台设备上，不进备份。
今天页点“排今天”：本地先算出空档（避开上课、12:00–13:30、17:30–18:30），连了 AI 就让 AI 排，AI 给的每一块都会先过本地检查，你确认后才写进时间轴。没连 AI 时用本地规则排。
平板网页版能不能直连模型待验证，不行就先在手机上用。

## 导入课表 PDF

课表页 → 导入 → 选择教务系统导出的课表 PDF。在本机解析，不上传。星期按 PDF 表格的列判断，节次、周次、地点从文字里读出，节次再按“我的 → 作息表”换算成时间。实习、网课这类不排节次的，会列在课表页下方“不排课的安排”。

## 课表 CSV 格式

用 WakeUp 课程表的模板，7 列：课程名称、星期、开始节数、结束节数、老师、地点、周数。
周数写 `1-16`、`1-8,10-16`；单双周写 `1-15单`、`2-16双`。节数按“我的 → 作息表”换算成时间，第一次用先核对作息表。
课表页 → 导入 → 下载 CSV 模板，可以拿到示例文件。

## 构建失败时

打开 Actions 里失败的那次运行，把红色步骤的日志复制出来发给 Claude。
